#### **Salary Calculator**



###### **Smart Salary Calculator –**

###### **A solution for personal financial management**





An interactive and accurate WEB site designed for employees in Israel, which allows for detailed calculation of net and gross salaries.

The site guides the user through the "step-by-step" process.





###### **The site includes:**



**Personalization -**

Entering employment details, workplace and position.



**Complex calculations -**

Managing hourly versus global wages, including taking into account tax credit points.



**Working hours management -**

A flexible system for entering regular hours or daily reporting in a table that automatically calculates overtime (125% and 150%).



**Deductions and additions -**

Weighting travel reimbursements, vacation days, sick leave, sick leave and leave deductions.



**Professional output -**

Creating a designed payslip simulation with the option of direct printing or saving as a file.
